# Support

## Documentation

Start with the [README](README.md), then [docs/](docs/): architecture, methodology, reproducibility, limitations,
use cases. Interactive API documentation is served at `http://127.0.0.1:8000/docs` when the backend runs.

## Questions

Open a GitHub issue using the most suitable template. If GitHub Discussions is enabled for the repository, use it for
open-ended questions.

## Bug reports

Use the **Bug report** issue form. Include version, OS, exact commands and logs — with synthetic data only.

## Feature requests

Use the **Feature request** issue form and describe the problem before the proposed solution.

## Research questions

Use the **Research question** issue form for methodology, assumptions, reproduction results or comparisons.

## Security problems

Do **not** post vulnerabilities publicly. Follow [SECURITY.md](SECURITY.md).

Support is best-effort; there is no guaranteed response time.
