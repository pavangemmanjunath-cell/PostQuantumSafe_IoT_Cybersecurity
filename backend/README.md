# safeguard-pq — backend

FastAPI multi-agent backend (`safeguard_pq`) of the TIPPSS-based framework: every finding is mapped to the six IEEE 2933-2024
TIPPSS pillars (Trust, Identity, Privacy, Protection, Safety, Security). Install with `pip install -e ".[dev]"`, run with `safeguard-pq serve`, test with `pytest`.
See the repository [README](../README.md) and [docs/architecture.md](../docs/architecture.md).
